# Quantum Core OS Public Canon

Status: public in-universe project reference

This file contains only the history and interpretation that may be treated as known from the terran point of view. Unknown ancient origins are intentionally not documented here.

## 2080: return of working computer infrastructure

After the collapse, regular functioning computer infrastructure returns in 2080 during the reconstruction.

NEHA'AR is central to the rebuilding of Gaia. Sandra Jansen and NEHA'AR develop CoreUI together in this period. CoreUI becomes a foundation of the new terran computer and interface generation.

For terran history, this is the visible origin of the later design lineage.

## 2080 to 2100: CoreUI lineage

CoreUI, the restored computing environment and the surrounding interface concepts continue to evolve during the reconstruction.

The recognizable early palette is based on white, blue and gold.

## 2100: Quantum Core OS

The Tri-Solaris Alliance introduces Quantum Core OS in 2100 as a further development of the CoreUI lineage.

Its mature visual language is based on:

```text
blue
black
white
gold
```

For the population of Gaia, this is a normal technological and visual evolution of the systems created during the reconstruction.

## 2163

By 2163, Quantum Core OS is an established everyday platform used across civilian and military environments of the Tri-Solaris Alliance.

The repository's terminal header represents a 2163 system snapshot, not the year in which the operating system was first introduced.

Example reference:

```text
Tri-Solaris Alliance // Quantum Core OS v2163.4
SYSTEM: Standard Alltags-OS (Klasse-3 Zivil / Militär)
KERNEL: Quantum-UNIX 6.163-TSA-generic
```

## Public information displays

The current Starlight Unit homepage design represents the visual family of public news and information monitors used in Hyperion Nodes and the cities of Gaia.

These displays are part of the same terran interface family as Quantum Core OS. They are specialized public-information surfaces rather than conventional websites from the in-universe perspective.

In Episode 2, such public information environments form part of the world in which the population reacts to and speculates about Ren.

## Terran GUI frames

The thin luminous frame language also appears in terran GUI systems such as the frame structures used around Ren's GUI ring.

Quantum Core OS uses this existing terran frame grammar for windows and system surfaces rather than inventing an unrelated desktop style.

## Knowledge boundary

Terrans do not possess a known historical narrative attributing this design lineage to an older non-terran civilization.

Public project documentation must therefore describe the lineage as:

```text
Reconstruction
    |
    v
CoreUI, 2080
    |
    v
Quantum Core OS, 2100
    |
    v
Quantum Core OS v2163.4
```

Any author-only origin information belongs outside public repository documentation.
